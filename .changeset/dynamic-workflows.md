新增持久化动态工作流：新 init 默认启用 workflow 配置，由宿主模型生成严格 JSON DAG，按真实依赖、节点读写范围及并发/尝试预算领取独立 token；不运行任意生成脚本或另一套 agent CLI。既有静态配置和快照保持可用，未配置的阶段角色不再隐式注入固定团队。

节点以逐项观察证据和结构化结果完成，支持原生新上下文评审、局部 replan、保留独立成功结果、依赖闭包失效、死宿主续领、取消与显式重试；status/events/report 带出节点状态、结果和修订历史。研究、真实检查/runtime、当前源/依赖/截图证据、独立评审与打包门禁仍不可跳过。评审结果绑定完整验证合同与实际验证代次，各节点回执绑定各自领取边界；取消与确定性执行使用事务领取互斥。更新宿主 skill 和定时唤醒指令，等待时先收集本会话 worker，避免提前退出或重复派工。

补齐多 agent 架构审查发现的无人值守边界：本地确定性失败返回受控修复图；子评审拒绝/finding 参与最终否决；按物理身份及保守大小写/Unicode 规则串行冲突资源；准入检查剩余回合、最低席位和结果传输可表达性，禁止退休 ID 退还 attempts。支持稳定 host PID/祖先校验与进程 incarnation，短命包管理器不再拥有 native token。跟踪命令经登记后启动的 POSIX 进程组 supervisor 运行，保护提交前崩溃窗口；drive 信号清理、总期限门禁、worker 代际锁和 UTF-8 跨块输出保持一致，未知所有权仍安全阻塞。
