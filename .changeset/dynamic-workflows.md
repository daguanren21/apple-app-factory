新增持久化动态工作流：新 init 默认启用 workflow 配置，由宿主模型生成严格 JSON DAG，按真实依赖、节点读写范围及并发/尝试预算领取独立 token；不运行任意生成脚本或另一套 agent CLI。既有静态配置和快照保持可用，未配置的阶段角色不再隐式注入固定团队。

节点以逐项观察证据和结构化结果完成，支持原生新上下文评审、局部 replan、保留独立成功结果、依赖闭包失效、死宿主续领、取消与显式重试；status/events/report 带出节点状态、结果和修订历史。研究、真实检查/runtime、当前源/依赖/截图证据、独立评审与打包门禁仍不可跳过。评审结果绑定完整验证合同与实际验证代次，各节点回执绑定各自领取边界；取消与确定性执行使用事务领取互斥。更新宿主 skill 和定时唤醒指令，等待时先收集本会话 worker，避免提前退出或重复派工。

补齐多 agent 架构审查发现的无人值守边界：本地确定性失败返回受控修复图；子评审拒绝/finding 参与最终否决；按物理身份及保守大小写/Unicode 规则串行冲突资源；准入检查剩余回合、最低席位和结果传输可表达性，禁止退休 ID 退还 attempts。支持稳定 host PID/祖先校验与进程 incarnation，短命包管理器不再拥有 native token。跟踪命令经登记后启动的 POSIX 进程组 supervisor 运行，保护提交前崩溃窗口；drive 信号清理、总期限门禁、worker 代际锁和 UTF-8 跨块输出保持一致，未知所有权仍安全阻塞。

切换为宿主项目上下文优先：init 固定当前会话或 --project 指定的真实源码根，已有项目原地继续，新建项目不默认落入 UUID 目录；显式 isolated 模式保留快照工厂语义。分离 live source 与混淆执行副本，迁移旧队列时保留原路径/历史并阻止活跃所有权被静默改写。交付给出源码、实际执行目录、配置的运行验收命令、产物与报告位置；复制产物核对摘要，源码导出是次级快照，变更后的 live source 不冒充旧证明。

移除 SMTP 及 notify.email，改为冻结 owner 目的地的宿主通知包、领取、完成和显式协调。凭据及 Gmail/Slack 等实际发送留给宿主；缺能力或外发失败不改变构建成功，未知发送结果不盲重放，旧回执不自动授权新通知。

按职责重组 apphx 和 obfuscator 的源码与内部 dist 路径，迁移所有调用者、资源 URL 与测试，不保留旧路径转发；公开 CLI 二进制路径不变。

新配置默认开启平台 UI 证据门禁：明确有无 Figma 的设计来源，覆盖移动安全区、桌面窗口、键盘焦点、大字体、响应式与可打断/减少动态效果的动效。最终批准要求冻结的真实捕获文件及哈希，保留子评审失败否决并在打包前复核，报告展示观察证据；旧配置保持原门禁，已开始任务不可降级关闭。产品、架构、设计等职责由模型按任务规划，并通过宿主 find-skills 或等价能力动态发现、评估和加载适用技能，不内置 Impeccable 整包副本、不固定角色与技能映射，不自动安装工具或 hooks。

状态查询、事件、取消与通知回执等控制操作使用冻结元数据，不因 live/execution 祖先变为失效链接而失去恢复入口；执行和领取仍校验真实项目边界。

项目上下文 CLI 回归测试区分结构化错误记录与 Node 22 SQLite 诊断输出，保留警告、退出码和错误内容断言，不把整个 stderr 误当作单个 JSON 文档。

混合归属恢复回归保留未知进程不得被误杀、进程组最终退出及禁止阶段重放的断言，不再假定活跃执行器与恢复器竞态中必须由恢复器记录 SIGKILL；独占恢复器的 TERM/KILL 覆盖保持不变。

修复 PR 风险：未知 Node 启动器需显式稳定控制器，宿主身份只在需要 native 领取时解析，显式 next 不重复下发其他活跃控制器 token；完整 drive 响应和研究产品组合使用有界预览并标明省略，完整记录仍可独立读取。中间子评审否决及时出现在报告，评审席位/图限制变化触发重规划；目录归属扫描限量并保守串行，保留硬链接互斥。

拆分 schema、平台 profile 与示例：init 从独立的纯配置 profile 取得框架/平台/产物命令，固定项目和控制目录后经既有 schema 校验，不再读取 examples。七个基础框架示例改为 profile 的生成产物，定制场景通过原有契约校验，测试流程拒绝生成漂移。现有平台组合、默认权限、工作流/UI 门禁和已有配置加载语义保持不变，不迁移校验库。
